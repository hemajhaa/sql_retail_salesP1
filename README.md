# 🛍️ Retail Sales Analysis | SQL Project

## 📌 Project Overview

This project analyzes retail sales data using SQL to uncover meaningful business insights related to **sales performance, customer behavior, product categories, profitability, and purchasing patterns**.

The goal of this project is to demonstrate practical SQL skills while solving real-world business problems that a **Business Analyst** might encounter.

---

## 🎯 Business Objective

The objective of this project is to analyze retail transaction data and answer important business questions such as:

* Which product categories generate the highest revenue and profit?
* Who are the most valuable customers?
* What are the peak sales periods?
* Which customer demographics contribute the most to sales?
* How does sales performance vary across different time periods?
* Which categories have the highest profit margins?

The insights from this analysis can help businesses make better decisions related to **sales strategy, customer targeting, inventory planning, and operational efficiency**.

## 5. Shift Analysis

Sales transactions were divided into three shifts:

* 🌅 **Morning:** Before 12 PM
* ☀️ **Afternoon:** Between 12 PM and 5 PM
* 🌙 **Evening:** After 5 PM

The analysis helps identify which shift receives the highest number of customer orders.

Example query:

```sql
SELECT 
    CASE
        WHEN HOUR(sale_time) < 12 THEN 'Morning'
        WHEN HOUR(sale_time) BETWEEN 12 AND 17 THEN 'Afternoon'
        ELSE 'Evening'
    END AS shift,
    
    COUNT(*) AS total_orders
    
FROM retail_sales

GROUP BY shift;
```
